dbc-matrix-audit

Static auditor for DBC communication matrices. 11 structural checks, two-revision diff, live frame decoding and CSV export — Python standard library only.

Revision diff

Comparing two matrix revisions produces 14 distinct codes. Two miss patterns are handled deliberately:

  • Same name, new ID. Comparing by ID alone degrades into "one deleted + one added", burying the actual cause. The tool pairs by name first and suppresses the misleading add/delete pair.
  • CRC DataID change. It hides inside a CM_ comment (CRC16 checksum (DataID: 0x61D2)), so a plain comment diff reports info. The tool regex-extracts it and escalates to error — every receiver will reject the whole frame.

Renames are matched by bit definition, so Bus_Off_Count → Bus_Off_Cnt is one DIF-REN, not a delete plus an add.
